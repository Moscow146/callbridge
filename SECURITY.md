# Security

The pairing token in the QR code lets a device act as your phone, so it can listen to the PC microphone. Treat the QR code like a password: do not post screenshots of it. "New code" in the Windows app invalidates the old one.

Report a vulnerability privately through [Security advisories](https://github.com/Moscow146/callbridge/security/advisories/new). Please do not open a public issue for it.
